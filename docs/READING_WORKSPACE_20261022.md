# 以阅读和批注为主的课程书架

## 合并的三个问题

1. 书架主屏被设备下载库、导入、排序、筛选、下载、维护等多行折叠面板占满。现在顶部两条紧凑横栏只保留课程与课件切换，课程选项收纳设备下载库/课程排序/归档，课件工具收纳导入、课件排序、移除、筛选、版本、下载、详情和维护。阅读器紧随切换栏，书签与批注紧接正文。功能不删除，原控件key、排序完整范围、移除确认/撤销保持。
2. 整页适配对scroller.clientWidth/Height和控件的自身宽度反馈敏感，滚动条与自动宽度控件变化可再次触发ResizeObserver。没有将截图里的114/117单独断言为某一浏览器bug；本次固定缩放选择器和百分比显示宽度、预留稳定滚动条槽、向下取整并留2像素安全余量，从布局与几何两端避免反复变化。视口、旋转和面板变化仍重新按比例适配，不能把不同页面/窗口强行锁成同一百分比。
3. 今日学习的“我的课程”确有硬编码`[:4]`截断。改为按原服务排序显示全部未归档课程，归档课程仍排除，每门可直接进入书架。

## 阅读区域

工作区CSS只对书架放宽页面宽度并减少留白，其他功能页保持既有宽度。顶部菜单固定132像素以便平板上完整显示文字。阅读工具栏紧凑排布；正文高度根据可视高度留出操作区，保留手动缩放、旋转、侧边预览、全屏和批注。相邻页预绘制、后台保存与长期设备下载库沿用上次修复；只要旧服务器还在device-library-r2，本包也包含相同已验证的reader_runtime.py和非阻塞保存实现，一次更新即可，不需先跑旧smooth包。
