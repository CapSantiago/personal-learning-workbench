## 1. 已实现的行为

- 保留学期与课程管理；默认应用切换到独立 M2 工作区。旧 M1 数据库和入口不被覆盖。
- 每个文件单独选择 managed_copy 或 external_reference；来源只允许专用合成 sources 目录。
- 托管复制保留来源，经过分块复制和 SHA-256 校验才成为就绪资料。引用只保存路径。
- 导入有持久请求 ID 与文件操作日志；重复请求复用原记录，换内容复用请求拒绝；相同内容的不同资料独立保留并提示候选。
- 资料搜索、详情、完整哈希检查及缺失/不可访问/可能变化状态；外部引用可显式重新定位。允许不同内容时仍保留原始基线并显示可能变化。
- 默认隐藏索引，保留正文和关系。永久删除托管正文必须先隐藏、没有任务/笔记/章节关联、输入精确资料 ID 单独确认。外部引用不提供原文件删除能力。
- 显式核对未完成文件操作。完整暂存文件可以继续提交；缺失或不一致现场保留为失败/隔离，不能静默跳过后发布完整备份。
- 完整目录备份覆盖数据库、所有保留托管正文（包括隐藏资料）和全部已登记笔记版本；外部引用逐条 included=false，备份/恢复不读取其正文。
- 独立验证清单、SHA-256、文件集合、数据库完整性、外键、版本与逻辑引用，拒绝损坏、遗漏和未知内部残留。
- 恢复前生成完整副本，恢复到新 UUID 数据集并验证，最后比较旧活动 ID 再切换。旧数据、失败新目录和备份都保留。
- 回滚前保存当前数据完整副本，再验证并切回恢复前数据集。
- 恢复日志持久化；未完成或含歧义的恢复阻止普通写入，必须明确确认后核对或回滚。
- 写入屏障覆盖课程、资料和维护操作，具有线程互斥及 Windows 跨进程锁；失活数据集不能继续写入。

正式任务、笔记编辑和 PDF 阅读业务未实现。备份对任务关联及多版本 Markdown 的覆盖使用直接构造的合成数据库/正文验证，不代表 M3/M4 页面已经存在。
