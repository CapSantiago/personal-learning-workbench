## 统一设计系统

完整规则见 [设计系统](../design-system/plw/MASTER.md)。主色沿用深绿 `#25665c`，正文 `#243b35`，辅助文字 `#53665e`，画布 `#f6f8f7`，内容白色；状态用文字与颜色共同表达。

字体使用本机系统中文无衬线，正文 16px，辅助信息 13–14px；标题 28/22/18px。间距以 4/8px 为基础，常用 8/12/16/24/32；组件圆角 8px，分组 12px。内容区域不用装饰性阴影，阴影仅用于浮层和 PDF 纸张。常规按钮约 38px，触屏关键按钮至少 44 CSS px；网页的 CSS 像素与原生应用 pt/dp 不混用。

## 信息架构

- 今日学习：标题与日期 → 最近阅读 → 待办 / 全部活动课程。只保留一个视觉主操作。
- 导航：品牌 → 学习入口 → 课程子列表 → 管理。保留全部路由、归档入口和登录退出行为。
- 课程列表/详情：筛选和正文清楚分区，原生表格、表单继续负责交互。
- 阅读页：课程与课件两行紧凑切换 → 阅读/批注工具 → PDF 主体 → 书签批注；导入、排序、版本、下载等继续在现有工具菜单中。
- 任务日程：待完成 / 已完成 / 全部，随后课程筛选、任务、编辑表单；现有截止和计划日期字段保留。本轮不新增日历模型。

## 分阶段实施计划

1. **基线与规范**：完成本审查、设计系统、隔离合成学习库和修改前截图。不读取或改写正式学习库。
2. **基础视觉与主要页面**：统一主题语义值，调整首页的主次操作、侧栏与课程/任务的密度；仅修改呈现层。
3. **阅读与触屏细化**：统一组件颜色和焦点，调整工具组和触屏尺寸，保留画布、保存与下载逻辑。
4. **真实浏览器验收**：桌面、平板、手机、横屏、文字放大及减少动态效果；检查主要入口、文字溢出、控件重叠、PDF 适配与交互。运行现有相关回归。
5. **交付**：提供前后截图、文件列表、测试记录、技术限制；如准备云端更新，用新版本独立包，已发布包不可覆盖。

## 数据与技术约束

本轮不修改数据库结构，不做迁移；不删除或清理用户文件、浏览器设备下载库、正式学习库，也不修改身份验证、路由和网络配置。验证使用新建的本机合成库。Streamlit 仍可能在服务端操作后重运行；CSS 不能消除网络等待或替代持久化，不能声称本次美化加速了首次下载。

当前只支持现有浅色主题；不承诺未设计和实测的深色主题。浏览器模拟 iPad 尺寸不能代替物理 iPad / Safari / Pencil 验收。CSS 部分依赖 Streamlit 的 testid 与组件结构，后续升级需要回归。
