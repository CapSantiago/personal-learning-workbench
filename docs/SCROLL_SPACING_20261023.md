# 阅读页滚动与首页课程间距修正

2026-10-23。只修改 `src/plw/workbench.css`，不修改数据库、课件、批注、下载库和阅读器 JS。

- 阅读页主容器底部留出约 35% 可视高度的滚动余量（192–416 CSS px）。页面到“书签与批注”后仍可继续滚动，把 PPT 往屏幕上方移动。该空间在外层，不改变 PDF 容器尺寸和整页适配。使用稳定视口单位，另保留 vh 回退；空课程书架也沿用此页留白。
- 首页“我的课程”原来使用紧凑零间距，而标题内部 Markdown 容器仍有 -16px 底边距，导致第一门课悬停底色覆盖标题。只在该列表标题中取消负边距并增加 8px 间隔，其余课程保持紧凑。

沿用 UI/UX Pro Max 的文字重排与间距原则。工具检索没有直接匹配“阅读末尾滚动余量”的规则，这部分按现有浏览器布局诊断设计，没有引入平滑滚动或动画。

## 验证

完整 Streamlit + Edge、隔离合成学习库，375/768/1024/1440px 下标题可见文字与第一按钮至少间隔 8px，悬停不重叠；四种尺寸阅读页滚动到底后能继续抬高阅读区，外层滚动不会改变画布尺寸或缩放值，无脚本异常和主页面横向溢出。

证据：`.sandbox/ui-design-scroll-home-accepted-4cee59bb-b8d0-4e62-9443-c07004685f38/report.json`。补充适配回归结果见项目状态。物理 iPad Safari 尚未实机验证。

## 安装

适用于已安装六色外观版 `plw:0.3.1-appearance-20261022` 的网站。只覆盖 CSS，旧版文件先做精确摘要检查；不接受未知改动。使用现有隔离验证、完整学习数据备份与配置快照，健康检查失败尝试恢复旧镜像。

```powershell
& "C:\Program Files\PowerShell\7\pwsh.exe" -NoProfile -File "E:\Projects\PLW\.sandbox\releases\Install-PLW-Scroll-Spacing-20261023.ps1"
```

密码仅输入本机终端。成功后重新打开网页即可，不用重新下载课件。云端部署需用户终端认证，本地测试不代表已更新服务器。
