# PLW 项目状态

更新：2026-10-13，Asia/Shanghai。当前版本 0.2.3，数据库仍为 schema 2。

## 本轮交付：多文件导入

- 课程书架提供“选择文件 → 导入所选课件 → 阅读”的主流程，系统文件选择器支持多选 PDF、PPT、PPTX，也支持拖入。每批 20 份/500 MiB，单份 200 MiB。
- 文件完整保存进学习库，原件保持不变；PDF 自动准备阅读版，PPT 自动调用本机 PowerPoint 转换。逐份显示结果，一份失败不阻止其余文件；转换失败保留原件，可重新选择重试。
- 同课程、同文件名、同 SHA-256 的已验证托管资料复用；同名不同内容分别保存。同一上传请求幂等，失败残留继续适用既有文件操作核对和完整备份。
- 旧路径添加入口移到“资料管理 → 高级：通过电脑路径添加”。书架普通导入不再要求绝对路径，也不需要选择存储模式。
- 默认启动器使用同源阅读路由，PDF、PDF.js 和 worker 都来自应用自身地址，去除阅读器对客户端 127.0.0.1 独立端口的依赖。仍只绑定本机 127.0.0.1。
- PPT 转换禁用宏并恢复调用前的 AutomationSecurity；仅处理隔离任务副本，不退出用户 PowerPoint。

## 私人网站方向与下一步

用户已明确选择私人网站，接受后续服务器费用，目标是电脑、手机和 iPad 在不同网络登录同一服务，共用完整课件、进度、笔记与标记。

当前完成上传与同源阅读基础，**尚未部署外网网站，尚未实现登录认证、HTTPS 或服务器迁移**。不会直接公开当前服务。服务器、域名、预算和部署地区尚未确定，也未购买云服务。

下一阶段按 [PRIVATE_WEBSITE_PLAN](PRIVATE_WEBSITE_PLAN.md) 完成运行环境移植与 PPT 转换验证、全路由登录保护、完整备份和演练，再部署私人 HTTPS 网站并用真实设备验收。跨设备保存集中到同一服务；其他设备刷新读取，暂不承诺离线修改自动合并。

## 使用

打开或刷新 http://127.0.0.1:8501/ 。课程书架 → 导入课件 → 选择文件 → 导入所选课件。

详细说明见 [README](../README.md)，上一版记录保留在 [V022_STATUS](history/V022_STATUS.md)。既有任务、笔记、阅读标记与备份能力保持。当前 Streamlit st.App API 版本锁定，升级需重跑同源阅读与上传集成测试。
