## 修改

- 浏览器当前页面内保留最近 3 份文档，按访问顺序淘汰；已知 PDF 文件总字节预算 96 MiB。单个当前文档超过预算时仍可打开，会释放其他文档。预算指原始 PDF 字节，不等同于整个浏览器进程堆内存上限。
- 同一课件返回时复用 PDF.js 文档、读取过的分段、阅读位置、文本和缩略图缓存。没有下载过的页面仍需要加载；离开浏览器或刷新页面仍需重新载入。没有增加浏览器磁盘持久缓存。
- 文档模型按数据集与版本区分；数据集、资源能力地址、文档摘要变化或用户主动重载时使旧对象失效。UI 继续调用现有完整校验，再传入 PDF 大小和摘要；没有减少服务器完整性/登录/跨站检查。
- 淘汰时销毁工作线程与文档对象，释放文本及缩略图缓存；如有未确认保存的操作，保留轻量操作模型。处理导入模块/文档异步加载被重置后的过期结果，防止旧任务覆盖新文档或清空新任务的等待状态。
