# PLW 设计系统

适用：Python / Streamlit 个人学习工作台，浅色主题。2026-10-22。

## 方向与来源

简约、可读、长时间使用；阅读和批注优先。UI/UX Pro Max 的简约风格和通用 UX 规则经核对后采用；其营销布局、展示型卡片及衬线字体匹配不适用，以下为项目适配方案，不是完整检索输出。详见 `docs/UI_UX_REVIEW_20261022.md`。

字体：`-apple-system, BlinkMacSystemFont, "Microsoft YaHei", "PingFang SC", "Segoe UI", sans-serif`。不下载网络字体。标题 28/22/18，正文 16，辅助 14/13，行高 1.55–1.65。品牌采用原创圆角几何 SVG 字标，82×31px，配 38px 书页标识，另保留可访问文本。数字采用 tabular-nums（页码、缩放、进度）。

强调色可在“课程与设置 → 外观设置”选择绿、黑、紫、蓝、黄、橙。由 `ui_theme.py` 统一提供 accent/hover/ink/text/soft/control/focus 语义值；bg、surface、sidebar 与错误语义保持固定。黄色实色按钮使用深字，浅色选中底使用独立深色 ink；不能把强调填充色直接当作所有状态的文字色。网站共享偏好独立保存于工作区 control，不修改学习数据库。

## 布局与组件

- 常规页面最大宽度 1240px；阅读页使用全部可用宽度。桌面左右内边距 32px，平板/手机 12–20px。
- 间距 4/8/12/16/24/32px；控件圆角 8px，内容分组 12px。避免重复套边框。
- 首页最近阅读为小型连续任务区域；最近一项主按钮，其余次级。课程入口用列表语义视觉，所有课程显示。
- 每页一个明显的主操作；管理操作在已有菜单/展开区中，不能移除。
- 常规按钮最小高度 38px，桌面阅读工具为 36px；触屏关键控件至少 44 CSS px。长文字换行，不使用固定卡片高度。
- 侧栏主入口使用浅绿底和 3px 内边提示；课程子列表使用缩进与独立选中底色。图标为装饰性 SVG mask，不改变按钮的可访问名称。
- 侧栏 hover/pressed 使用浅中性底和轻阴影、深色文字/图标；其规则必须优先于通用主按钮 hover，避免文字和底色相同。设置分组保持稳定标识。
- 阅读页标题行与学期/教师说明纵向分层；压缩 caption 段落间距时必须同时取消原生容器的负边距补偿，按真实文字边界检查后续控件间隔。
- 手机保留原生侧栏展开按钮，并为顶部导航与键盘焦点留出空间，滚动内容不会透过透明导航栏。
- 阅读器按工具组换行，不改变 DOM 阅读顺序；保留稳定缩放选择器、缩放值宽度与滚动条槽。
- 适配中绘制不得反复改变容器大小；阴影仅用于纸张和浮层。不会为了美化增加 PDF 渲染、预取、下载请求。
- 状态：hover/pressed 使用颜色，不改变宽高；focus-visible 明确；disabled 不可点击；保存、错误、完成均显示文字。
- 不使用装饰性渐变、毛玻璃、emoji 导航或无意义统计卡片。保留原生可访问控件和标签。

## 响应式与可访问性

主要检查宽度 375/768/1024/1440px，补横屏和 200% 字号。手机自动折叠原生导航，主内容不横溢；PDF 手动放大和表格内部滚动属于有意交互，不能让整页溢出。预览栏在手机作为可关闭的覆盖层，保留现有“页面预览”开关。

普通正文与辅助文字目标至少 4.5:1；按钮边界与焦点目标至少 3:1。减少动态效果设置下取消非必要过渡。不禁用浏览器缩放；不添加依赖 hover 的独占入口。

## 实施边界

只涉及 UI 标记、原生组件的呈现参数和 CSS。业务回调、SQL、schema、文件、认证、路由、设备库和保存协议保持现有实现。物理触屏、Safari 和深色模式未验收时应如实注明。
