# PLW 项目状态

更新：2026-10-13，Asia/Shanghai。当前版本 0.2.2，数据库仍为 schema 2。

## 本轮：简洁学习界面

- 侧栏默认四个常用入口：今日学习、课程书架、任务管理、笔记。其他入口收在“课程与设置”，当前管理页会自动展开；学习库路径移入备份页详情。
- 首页显示今日/逾期/近期任务摘要、继续阅读卡片、课程入口。继续阅读绑定准确的资料和阅读版本，清除会遮挡目标的旧筛选；最近翻页或保存标记后会出现，未读未标记的新副本不会挤占列表。
- 课程选择在书架、任务、笔记和章节页之间保留；空学习库提供下一步按钮，失效/归档课程和过期目标安全回退。
- 书架优先显示阅读区，批注、新版本、导入和维护按需展开。图形标注与 PDF 阅读器逻辑保持不变。
- 任务先展示待办列表，表单采用紧凑分栏，备注/耗时/资料折叠；课程和学期先看列表、按需编辑。笔记通过编辑/阅读预览标签页切换，公式与历史版本保留。
- 统一浅色背景、绿色主操作、系统字体、留白和圆角；隐藏 Streamlit 开发工具栏。窄窗口保留侧栏菜单，不出现整页横向溢出。

没有安装或升级依赖，没有修改系统设置、ROS、SRTP、Conda 环境。没有修改数据库迁移，没有导入、转换、删除或移动用户真实课件。所有编辑验收使用新的合成学习库。

## 使用与边界

正式入口：http://127.0.0.1:8501/ 。打开或刷新后使用新版，现有课程、课件、笔记、标记继续保留。

“继续阅读”按最近翻页或标记排序；仅打开第一页且没有任何保存行为不会记录为最近阅读。文字批注需要点击保存；笔记预览需要先提交“保存笔记”或“预览草稿”。页面切换并不提供所有未提交表单的自动草稿保存。

仍采用单页阅读。连续滚动、缩略图、OCR、文字选择高亮、笔压及批注写回 PDF 留待后续独立优化；本轮没有增加 AI 或联网依赖。
