# Personal Learning Workbench — 产品需求

版本：M2 实施状态 + 课件阅读专项需求基线  
日期：2026-10-11  
状态：M1 学期、课程及数据基础已实现；M2 资料管理、完整备份、恢复与回滚已实现，并通过自动化和真实浏览器的合成数据验收。仍不得导入真实学习数据。

## 1. 目标与使用者

PLW 是为机器人工程专业大学生日常学习设计的 Windows 11 本地工作台。它把课程、教学资料、作业、实验、考试、章节、知识点与 Markdown 笔记组织在一起，帮助使用者找到资料、决定下一项学习任务并记录学习结果。

当前产品优先级调整为：**按课程整理 PPT/PPTX 和 PDF，像电子书一样连续阅读，并在课件页上做标记。** PDF 是独立入口，直接阅读，不依赖 Office；PPT 转为固定阅读版本。先形成课程书架、继续阅读、标记与回看闭环，再扩展任务和知识管理。用户已确认静态阅读优先，动画可用 PowerPoint 打开；书签、文字批注、重点/疑问、荧光笔、框选、手写均为核心需求，不把后一组降为无期限可选项。专项设计与分阶段验收见 [COURSEWARE_READER.md](COURSEWARE_READER.md)。

第一版为本地优先、单用户应用。安装和准备依赖后，不联网、不配置 AI API 也能完成全部基础学习流程。离线运行不等于已经支持离线安装；完整离线安装包与依赖包仓库后续评估。

PLW 不接管现有 SRTP、ROS、Conda、代码工程或仿真环境。机器人课程的工程资料可以作为文件索引，但不会被 PLW 执行、修改或自动迁移。

### 2.2 V1 必须形成的闭环

核心闭环：创建课程 → 整理课件顺序 → 打开阅读 → 翻页、标记与批注 → 下次继续阅读或集中回看疑问 → 完整备份并恢复标记及其对应页面。完整 V1 再增加任务完成、Markdown 笔记和知识状态。

V1 包含：

- 学期、课程的创建、编辑、搜索、归档及课程主页。
- 资料逐项选择托管复制或外部引用，文件检查、重复提示、重新定位和安全删除语义。
- 按课程建立课件书架，显示缩略图、顺序、最近阅读位置和标记数量；支持整理顺序及可选章节分组。
- PPT/PPTX 的固定阅读版本、本地 PDF 阅读；连续滚动/单页、缩略图跳页、缩放、适合宽度、专注阅读及位置记忆。
- 书签、文字批注、重点/疑问、文本或区域荧光笔、矩形框选、鼠标/触控笔手写；编辑、删除、撤销和重做，按课程与课件回看标记。
- 作业、实验、考试、预习、复习和项目任务，以及多资料关联。
- 今日任务、近期截止、逾期、最近课程和快速添加。
- 章节、知识点状态、Markdown 笔记、行内及独立 LaTeX 数学公式。
- 内嵌课件阅读器是核心发布门槛；系统默认阅读器/PowerPoint 为打开原件与动画的补充入口。
- 名称、标题、备注等元数据的基础搜索。
- 数据库、托管文件和全部保留笔记版本的一致备份、验证和恢复。

V1 暂不包含：

- AI、OCR、PDF 全文检索、自动知识诊断或知识图谱。
- 跨设备同步、多人协作、远程访问和云端文件上传。
- 重复任务、系统提醒、番茄钟、自动计时及自动复习推荐。
- 与其他 PDF 软件互通批注、跨设备阅读位置同步、自动扫描磁盘或自动整理原文件。PLW 内本地标记和位置记忆已纳入核心范围。
- 直接运行或管理 ROS、Conda、SRTP 工程。
- 物理文件去重、自动清理旧备份，以及外部原件的自动快照/完整副本。用户明确生成的 PDF 阅读副本属于阅读专项范围。

## 3. 产品原则

1. 用户文件安全优先于导入速度；原文件始终保持不变。
2. 学习资料记录与实际文件是两个概念。解除关联不等于删除文件。
3. 显示真实状态；不能把“路径存在”当成“内容完整一致”。
4. 任务完成与知识掌握分开记录，不自动互相推断。
5. 使用普通 Markdown 文件和可解释的关系清单，便于离开本工具后继续使用资料。
6. 首页优先呈现“继续阅读”“课程书架”和“待回看的疑问”，后续再补充今日任务；翻过页面不代表掌握知识。

### 4.1 任务与时间语义

- 截止支持“仅日期”“具体时刻”“无截止”；仅日期截止到用户本地该日结束才逾期。
- 日期截止保存为本地日期，具体时刻保存 UTC 时刻并保留时区语义；默认显示 Asia/Shanghai。
- 任务状态为待办、进行中、已完成、已取消。只有未完成且未取消的任务参与逾期统计。
- 增加可选计划日期以表达“今天准备做”，不把计划日期冒充截止日期。
- 今日任务包括计划今天或今天截止的未完成任务；逾期单独展示。近期截止默认未来 7 天，可筛选。
- 预计与实际耗时使用非负整数分钟，V1 由用户手动填写，不需要后台计时。

### 4.2 文件语义

- managed_copy：复制到独立的数据集内部，保留原始路径作为来源信息；以后原文件移动不影响托管副本。
- external_reference：仅记录路径和可取得的元数据，不复制正文；用户重新定位时更新当前引用路径，保留最初来源。
- 同一个文件可对应多个独立资料记录。M2 导入结果与详情展示相同 SHA-256 的候选记录；不自动合并，也不建立共享托管文件。直接复用已有资料的任务/笔记选择器在 M3/M4 实施。
- 托管复制成功须校验大小与 SHA-256；M2 两种存储模式在首次添加时均执行完整哈希，不实现大文件延后哈希。大小或修改时间变化表示可能变化，不能直接证明内容改变。
- 缺失或不可访问不自动删除记录、不猜测新路径。重新定位需用户选择，内容不同需明确确认允许切换路径。M2 保留最初 original_path 和导入 baseline_sha256，新的内容记入 observed_sha256，继续显示“内容可能变化”；没有无历史记录地接受并覆盖新基线的功能。
- 从资料列表移出索引采用可恢复的逻辑删除；历史关联显示“已移出索引”，不冒充正常资料。永久删除托管文件前须展示受影响关系并先处理仍在使用的关联。
- M2 永久删除仅允许已隐藏、已完成导入、无任务/笔记/章节关联、内容仍符合基线的托管副本，并要求逐字输入资料 UUID。来源文件不受影响；外部引用无物理删除入口。已经删除正文的记录不能仅靠恢复索引找回正文。
- 导入中断后需显式点击文件操作核对。完整且匹配基线的暂存/最终文件可完成提交；缺少完整文件的操作保持 failed，不一致或双份残留保持 quarantined。未解决操作阻止完整备份；不承诺全自动恢复或自动清理。

### 4.3 笔记语义

- Markdown 正文以 UTF-8 的 .md 文件保存；数据库保存标题、关联、版本元数据及当前版本指针。
- V1 以内置编辑器为主。外部编辑器改动已保存版本不自动覆盖或吸收，而是提示冲突并提供另存新版本路径。
- 手动保存应提供成功、失败与未保存状态；保存失败时尽量保留当前会话中的编辑文本。V1 不承诺浏览器或系统崩溃后恢复尚未保存文本。
- Markdown 中禁止执行原始 HTML/脚本；外部图片等网络嵌入默认不加载。普通外部链接仅在用户点击后交给浏览器。
- 公式渲染资源随应用依赖准备，不以在线 CDN 作为正常运行前提。

### 4.4 课件阅读与标注语义

- 保留原始 PPT/PPTX，阅读使用固定 PDF 页面；动画和视频仍在原软件打开，不承诺转换全部动画中间步骤。
- 外部引用默认仅保存路径。生成本地阅读副本属于额外、明确的用户操作，说明它会保存课件内容并占用磁盘；拒绝生成时保留原软件打开入口。不能借“缓存”名义静默复制引用内容。
- 每次转换结果绑定源文件哈希、阅读 PDF 哈希和页信息。来源改变或重新转换产生不同 PDF 时建立新阅读版本，旧标记留在旧版本，不按同页码自动搬移。
- 标记保存独立于原 PPT/PDF；不回写来源。课程页提供“全部标记/重点/疑问”，疑问可手动设为已解决；已解决不等于知识点已掌握。
- 文本高亮依赖可用文字层；扫描页或图片公式可用区域荧光笔、矩形和手写。OCR、公式识别与全库全文搜索后置。
- 首版以鼠标和触控笔基本输入为目标，是否支持压感和防误触须有实际设备验收，不预先承诺。
- R1 的书签与文字批注是阶段交付；R2 的荧光笔、框选和手写全部通过前，不能宣称阅读标注专项完成。

### 5.2 关键用户流程

1. 添加资料：输入本地文件路径 → 检查并预览文件信息 → 逐项确认模式和课程 → 显示重复提示 → 提交 → 显示每项独立结果。路径导入为主，不承诺浏览器上传能够取得原始磁盘路径。
2. 日常学习：首页“继续阅读”或课程书架 → 打开课件上次位置 → 添加书签/批注/高亮/手写 → 确认已保存 → 下次继续阅读或回看疑问；M3/M4 再接入任务、笔记与知识状态。
3. 资料丢失：显示缺失 → 用户选择新位置 → 比较内容校验 → 相同内容重连，或明确允许不同内容路径 → 保留原始路径与基线并标注变化。
4. 课程归档：预览未完成任务 → 归档 → 默认列表隐藏，但历史资料、笔记和任务仍能查询；归档不自动完成任务。
5. 完整恢复：选备份 → 校验清单、正文与数据库 → 查看范围并输入当前数据集 UUID 确认 → 保存恢复前完整副本 → 恢复到新数据集并验证 → 比较并切换活动指针 → 界面载入新活动数据。失败保留旧数据和恢复日志；切换结果不明确时先核对恢复状态，再继续写入或明确回滚。

M2 完整备份包含数据库、托管文件、所有保留笔记版本和必要配置。外部引用报告逐项列出 included=false，并明确未在备份时重新检查外部正文；备份验证成功不表示外部引用现时可访问。备份目录的 complete.json 是发布标记；未完成目录不得作为有效备份。

## 6. 非功能与运行约束

- 默认仅监听 127.0.0.1；不开放公网或局域网，不修改防火墙。
- 使用 Python 3.14.3 的项目独立虚拟环境；不改动现有 Conda、ROS 等环境。
- 学习数据与源代码分离；程序启动不应静默初始化未确认的真实数据目录。
- 不上传资料内容、笔记或路径到外部服务；不依赖 AI/API key。
- 读写路径须支持中文和空格；遇到权限不足、占用、长路径限制须准确报告，不能自动修改系统策略。
- V1 支持一个应用进程、一个活动数据集；多个浏览器会话仍必须遵守同一写锁和版本检查。
- 正常退出、异常中断及重启后，不得将半成品文件显示为成功导入。
- 不使用硬编码性能数字作为已验证结论；M0/M5 在合成数据上记录运行机器、规模及实测结果。

## 7. 发布验收门槛

1. 在没有 AI 配置且外网不可用的条件下完成全部基础学习闭环。
2. 引用模式在导入、重定位、删除记录、备份、恢复的任何路径中均不修改原文件。
3. 多个任务引用同一资料时，解除一个关联不会破坏其他关联。
4. 从完整备份恢复到空数据集后，数据库关系、托管文件和保留笔记版本一致；外部引用遗漏清晰可见。
5. 损坏备份和恢复中断不改变原活动数据集，具有可执行的回滚流程。
6. 从未激活 Conda 的新 PowerShell 7 会话按 README 启动成功。
7. 自动化测试、人工验收、未完成项均有实际记录；不将 PoC 结果表述为生产功能完成。
8. 两门合成课程的多份课件可独立整理、续读和回看全部七类标记；缩放、重启和完整恢复后页面与位置正确；课件更新不会错配旧批注。
