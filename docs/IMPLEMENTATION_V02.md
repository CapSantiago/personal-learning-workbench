# 0.2.0 实现说明

本轮根据“按计划开发到框架可用，然后等待优化指令”完成统一可用入口。R0 探针和旧 M0/M1/M2 页面保留；日常入口改为 app.py → ui_workbench.run。

## 架构

- Streamlit 管理页面、PDF.js 本地阅读组件、Python 服务、SQLite、数据集内部不可变文件。
- 课程/资料沿用 LearningService / MaterialService。Workbench 实现任务、章节、知识点、笔记版本、阅读版本及标记。
- ReaderAssets 是只读回环资源服务，只提供登记的 PDF 和 vendor 清单资源，随机令牌、哈希校验，无任意路径/目录读取接口。数据集切换后旧数据集请求失效。
- PowerPoint 转换由有超时的 PowerShell 子进程完成，输入是 jobs 下的独立复制件。只关闭自己打开的演示文稿，不退出 PowerPoint 应用。失败可手动导出 PDF；PDF 导入不依赖 Office。
- PDF 结构检查调用现有 bundled Python/pypdf 子进程。PDF.js 已复制进项目并包含许可证；本轮未安装依赖。
- 正式库默认 E:\PLW-Data，备份 E:\PLW-Backups；首次确认创建。测试环境默认拒绝真实文件，正式库允许用户显式提交的本机普通来源文件。链接、重解析点、额外硬链接、设备名和备用流仍拒绝。

## schema 2 与关系

001_core.sql 未修改。002_workbench.sql 是新增迁移：

- materials.position；tasks / chapters / knowledge_points.revision。
- reading_editions：material_id 外键、source_sha256、不可变 PDF 路径/校验值/大小、页数、转换器、创建时间。
- edition_pages：(edition_id,page) 复合主键；页码从 1 开始。
- reading_progress：每版一行，页码复合外键、revision、更新时间。
- annotations：版本与页码外键，类型、文字、归一化图形坐标 JSON、疑问解决状态、软删除、revision、时间。
- workbench_requests：持久请求 ID、规范 payload 与结果，重复请求不重复提交，换内容复用 ID 被拒绝。
- content_operations：edition / note 的 durable intent，暂存路径、目标路径、校验数据与提交状态。

任务/笔记/章节复用原关联表，服务要求资料属于同一课程。任务支持六类、日期或精确时间、计划日期、优先级、状态、耗时。知识点采用四级学习状态。

笔记正文是 UTF-8 Markdown，文件不可覆盖，每次保存生成新 revision。笔记 current_revision 外键延迟到提交校验。保存、历史恢复、正文与关联在同一次数据库事务内完成。历史恢复会另建新版本。

阅读 PDF 的字节及页序是标记定位依据；坐标归一化到未旋转 CropBox 左上角，缩放和旋转通过 PDF.js 变换换算。旧版永不自动换到新版。当前页表只存页码；CropBox/尺寸由不可变 PDF 读取，不冗余保存。手动导出的 PDF 标明幻灯片页映射未经验证。

## 文件提交与备份

工作区写锁覆盖文件和数据库提交。新内容先暂存在工作区 jobs，记录 durable operation，验证语义与 SHA-256，复制到另一完整暂存文件，再在同卷通过 Windows 不覆盖 rename 发布。随后事务提交内容记录、关联、进度和操作完成状态。

中断后目标存在则校验并继续提交；目标不存在则从校验通过的暂存正文重试。可以显式取消尚未发布的操作，草稿保留。有未完成内容操作时完整备份拒绝成功。

完整备份扩展 reading_pdf 类型，包含全部阅读版本、所有笔记版本及数据库里的所有标记/进度。manifest 中外部原件仍 included=false；页面另列包含的阅读副本。托管正文存在阅读版本时禁止物理删除。

历史 schema 1 备份使用只读 snapshot connection 和对应版本 schema 验证，不偷偷迁移。恢复副本先对照原表列/正文核对，再迁移、验证并切换，源备份不变；回滚可切回旧 schema，下一次主界面显式提示升级。未知新版本拒绝。

## 可用范围和优化边界

| 里程碑 | 本轮状态 |
|---|---|
| M0/M1 | 保留审计及数据、学期、课程基础 |
| M2 | 资料管理与全量备份恢复，扩展新版和旧版兼容 |
| R1/R2 基础 | 课程书架、独立 PDF 版、页码、全部基础文字/图形标记、撤销恢复、标记回看 |
| M3 | 六类任务、截止与计划日期、耗时、关联及首页任务汇总 |
| M4 | 章节、知识点、Markdown/LaTeX、笔记历史、资料关联 |
| M5 本机首版 | 统一入口、启动脚本、使用文档、自动化和浏览器验收 |

尚未把所有增强设计实现为功能：封面/逐页缩略图、连续滚动、全文检索/OCR、文字选择高亮、笔压防误触、批注写回 PDF、任意阅读页锚点插入笔记、所有复杂 PPT 的保真保障和独立安装包。当前按单页阅读和基础保存闭环交付，后续只在用户指令下继续优化。

限制：单用户本机应用；多个标签页冲突拒绝覆盖，不做自动合并。初始库和备份均在 E 盘，用户应把完整备份另存其他磁盘。操作系统级断网和长期压力验收未执行，浏览器验收使用拦截非回环请求的隔离上下文。
