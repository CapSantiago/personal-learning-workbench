# PLW 简约工作台界面更新

本次是呈现层渐进改进，设计前审查与方案见 [审查文档](UI_UX_REVIEW_20261022.md)，统一规范见 [设计系统](../design-system/plw/MASTER.md)。

## 更新内容

- 侧栏品牌改为紧凑书页标识、PLW 名称与中文说明；导航左对齐，课程使用缩进子层级；浅色选中状态和细边提示替代大面积实心色块。
- 主应用、阅读器和设备下载库共用一份设计变量；本机中文字体、深绿色、中性背景、统一边界与键盘焦点。
- 首页仅最近一次阅读使用主按钮；保留全部课程入口，降低次要操作的权重。课程详情、表单、任务与日期信息采用同一套文字和间距规范。
- 保留阅读区首屏优先、稳定的整页适配和现有工具菜单；触屏关键按钮至少 44 CSS px。窄阅读区收起重复的缩放滑杆和百分比文字，仍可用缩放选择器、加减和 Ctrl+滚轮完成相同操作，批注工具完整保留。

没有更改数据库结构、用户资料、课件版本、路由、认证、HTTPS、下载库协议或保存逻辑。聚合更新包包含此前已交付的连续翻页与书架布局修复；无需先运行旧更新包。

## 安装与回退

最终包独立命名为 `PLW-UI-Design-20261022-r2.zip`，入口为 `.sandbox/releases/Install-PLW-UI-Design-20261022-r2.ps1`。r2 补充手机原生导航栏的背景与焦点留白，避免滚动文字透过导航按钮；首个本机候选包保留但不作为交付入口。入口只接受三种已知镜像及其完整源码摘要：device-library-r2、reader-smooth、reading-workspace。若运行版本不同或源码有额外改动，会在修改前退出。

执行顺序：载荷摘要 → 旧版完整身份 → 隔离派生镜像与合成验证 → 当前完整学习库备份 → 环境快照 → 切换 → 健康检查。切换阶段失败尝试恢复原环境和镜像；原镜像、原数据、完整备份、旧发布 ZIP 均保留。不会清空浏览器的课件下载库。

服务器密码只在本机终端输入，不发到聊天。脚本成功仅代表服务启动；真实课件、物理 iPad、Safari 和 Pencil 仍需要设备端验收。

没有数据迁移，因此回退不需要迁移数据库。若成功更新后需要人工回退，可用脚本输出的 `Previous environment` 精确路径恢复环境并重新启动旧镜像；先核对该路径和当前运行镜像，不删除任何学习数据或下载副本。

## 限制

- 本轮统一浅色主题；不宣称已支持深色主题或完整无障碍认证。
- Streamlit 原生表格可在自身区域横向滚动；PDF 手动放大可在画布内滚动，主页面不应横溢。
- CSS 依赖 Streamlit 1.65 的组件结构；升级框架后需回归。没有新增运行时依赖或外部字体。
- 页面美化不改变服务器出口带宽或首次课件下载速度。

本机浏览器证据和回归结果另见 `UI_UX_VERIFICATION_20261022.md`；本机通过不等同云端已部署或物理 iPad 已通过。
