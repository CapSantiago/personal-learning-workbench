## 本轮实现

- 新增 scripts/reader_probe：合成文件生成、PowerPoint 转换验证、PDF.js 资源服务、Streamlit v2 组件、独立标记存储、启动器、浏览器与重启验证脚本。
- 新增 tests/test_reader_probe.py，共 16 项契约测试，覆盖保存重试、重复请求、版本冲突、版本隔离、越界页号/几何和路径边界。
- 原生 PDF 直接阅读，不需要 PowerPoint。PPTX 和旧 PPT 使用现有 PowerPoint 转为固定 PDF 后走同一阅读组件。
- PDF.js 5.6.205 从已有 Codex bundled runtime 复制到本实验目录，附许可证及文件 SHA-256 清单；没有下载或安装新依赖。文档生成用已有 bundled runtime，应用仍用原项目 .venv。
- 资源服务仅监听 127.0.0.1:8504，采用随机访问令牌、文件白名单、来源校验和哈希检查；不暴露磁盘目录。8503/8504 的监听地址已实际核对。
- 标记存规范页面坐标，以 PDF 哈希区分本实验版本；R1 仍需正式的资料/阅读版本 UUID 模型与数据库迁移，不能直接把此探针 JSON 当正式数据层。

## 尚未执行或尚未实现

- Office 原生 OMML 公式、SmartArt、嵌入对象、动画逐步覆盖、缺字体、受保护/加密课件等复杂保真矩阵未通过本样本证明；当前公式主要是文本表达和 PDF 绘制分式。
- Office 自动化超时、弹窗与恶意输入隔离未完成生产级封装；本轮脚本只接受合成实验目录，不对用户任意 PPT 开放。转换失败不会改写原件，但未声称所有 Office 异常均已自动恢复。
- 峰值内存、长时间连续手写、可见笔迹延迟、真实触控笔压感/防误触、超大图片 PDF 和完整 OS 断网尚未实测。
- 仅几何标记验证；选中文字的多行高亮、文字批注、书签、撤销重做及正式课程 UI 尚未实现。
- 本实验 JSON 不接入 M2 备份。R1 必须在保存正式阅读版/标记前同时完成旧备份兼容、完整备份和恢复，不能让用户把合成原型当生产工具。
