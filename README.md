# Personal Learning Workbench

Windows 11 本地个人学习工作台，版本 0.3.1。课程书架、PPT/PDF 阅读和标记、任务、章节、知识点、Markdown 笔记及完整备份已接入统一入口。基础功能无需联网或 AI API。

0.3.1 增加 Linux 文件锁与可配置数据目录、schema4 路径兼容迁移、Docker/Compose准备、云端完整ZIP备份下载及维护命令。现有Windows schema3本地库可继续使用，不自动升级。Docker实际运行、Oracle实例、Tailscale和真实iPad验收待完成；尚未上线。维护者GitHub：CapSantiago；私有仓库为 [personal-learning-workbench](https://github.com/CapSantiago/personal-learning-workbench)。新部署优先见 [CLOUD_DEPLOYMENT](docs/CLOUD_DEPLOYMENT.md)、[CLOUD_DATA_BACKUP](docs/CLOUD_DATA_BACKUP.md)、[UPDATE_WORKFLOW](docs/UPDATE_WORKFLOW.md)。

## 日常使用

- 左侧四个常用入口：今日学习、课程书架、任务管理、笔记。学期、课程、资料、章节、备份与说明收在“课程与设置”中。
- 首页“继续阅读”回到最近翻阅或标记的课件，保留具体版本和页码；直接点击课程名进入它的书架。
- 首页待办按截止时间从早到晚排列，未设截止时间的放最后；逾期任务用深色标记，末尾显示“正常 / 重要”。已完成、已取消或已归档课程的任务不显示。
- 点击每条待办的“完成”，立即从待办移入“已完成任务”存档；保留完成时间、备注、耗时与资料关联。首页和任务管理可进入存档，按课程筛选或搜索，也可“恢复待办”。完整备份包含存档；修改已完成任务详情不会改变原完成时间。
- 左侧点击“课程书架”展开课程列表，点击课程进入专属书架；当前课程高亮，再次点击“课程书架”收起列表。主区直接显示课程名称，不再重复选择课程。
- 课程标题旁的“课程选项”支持课程上移、下移和指定位置。所有未归档课程共用顺序，刷新后保留；首页、侧栏和课程选择器同步显示。删除课程须明确确认，实际归档并保留内容，可撤销；新建和恢复课程追加末尾。
- 书架中“调整课件顺序”支持上移、下移或指定位置，刷新后保留；新课件按导入顺序追加。点击“导入课件”可多选文件。
- “移除课件”经确认后从书架隐藏课件，可立即撤销，也可从资料管理恢复；文件、版本、进度、标记和已有任务关联保留。
- 阅读默认整页适配，横竖页面按比例完整放进阅读框。左侧页面预览可点击跳页，两侧箭头与方向键均可翻页；窄屏默认收起预览，可用“页面预览”按钮展开。
- “下载与离线阅读”支持下载 PDF 阅读版和托管原件。保存到设备后可断网用 PDF 阅读器打开；不含 PLW 标记，不自动同步离线修改。“生成阅读副本 / 添加新版本”可直接选择上传已导出的 PDF，无需填写电脑路径。
- 缩放支持 Ctrl＋滚轮、连续滑杆、加减按钮及更多预设档位，手动范围 25%–400%；普通滚轮保留滚动，放大后可拖动阅读。选择“整页适配”或“适合宽度”恢复自动适配。文字标记在“书签与批注”中添加。
- 任务页先看待办列表；展开“添加新任务”或选择已有任务编辑。笔记通过“编辑 / 阅读预览”切换，修改后先保存或点击“预览草稿”。
- 任务截止日期和计划学习日期可点击日历选择年月日；精确截止时间按北京时间选择或输入小时、分钟。重要程度为“正常 / 重要”。
- 切换任务、书架、笔记时保留所选课程。窄窗口用左上角菜单打开导航。

## 启动

在 PowerShell 7 运行：

```powershell
& 'E:\Projects\PLW\.venv\Scripts\python.exe' -X utf8 -B 'E:\Projects\PLW\scripts\launch.py'
```

打开 http://127.0.0.1:8501 ，终端按 Ctrl+C 停止。也可运行 `scripts/start.ps1`；执行策略阻止脚本时使用上述 Python 命令，无需修改系统策略。端口占用可加 `--port 8502`，浏览器使用同一端口。启动器只监听 127.0.0.1，同一项目只允许一个主服务，关闭使用统计并保留 CORS/XSRF 防护。默认启动器将阅读 PDF、PDF.js 与应用放在同一地址和端口下，使用随机令牌限制资源范围，无目录浏览。旧的直接 streamlit run 方式只保留本机兼容，不用于网站部署。

## 第一次使用

1. 在欢迎页确认创建空学习库。普通打开网页不会初始化数据库。
2. 首页引导创建学期和课程；以后可在左侧“课程与设置”中管理。
3. 在左侧展开“课程书架”，点击课程，展开“导入课件”，点击“选择文件”。电脑会打开系统文件选择器；支持一次选择多个 PDF、PPT/PPTX，也可拖入文件。
4. 点击“导入所选课件”。每批最多 20 份、合计 500 MB，单份最多 200 MB。完整文件保存进学习库，原文件不变；无需输入电脑路径。
5. 系统自动准备 PDF 阅读副本。PPT 使用本机 PowerPoint 静态导出；导入结果逐份显示，点击“阅读刚导入的课件”打开。转换失败仍保留上传原件，可以重新选择重试，或在版本工具中使用自己导出的 PDF。
6. 默认整页适配和拖动阅读，点击左侧缩略图跳页，点击阅读区两侧箭头或用方向键翻页。Ctrl＋滚轮或滑杆缩放，可旋转、自动适宽或进入专注全屏。展开“查找课件文字”，输入关键词列出匹配页，点击结果跳转。需要标记时选择书签、批注、重点、疑问、区域荧光笔、框选或手写。图形可撤销/恢复，页码和标记持久保存。
7. 添加任务、章节与知识点，在 Markdown 笔记中使用 `$…$`、`$$…$$` 公式。笔记历史版本保留，可导出 Markdown。
8. 定期创建完整备份，并将整个备份目录另存到其他磁盘。

正式学习库为 `E:\PLW-Data`，普通备份为 `E:\PLW-Backups`。两者由首次确认和备份操作创建；源码与专属环境留在 `E:\Projects\PLW`。

## 文件与版本

同一课程重复导入同名且内容相同的文件会复用已有资料；同名但内容不同的文件分别保留。一份失败不阻止其他课件导入。

电脑路径导入保留在“资料管理 → 高级：通过电脑路径添加”，可逐份选择托管复制或外部引用；网站日常使用应选择完整上传。资料可搜索、检查缺失或变化、重新定位外部路径、隐藏索引。隐藏保留文件；永久删除托管文件须另行输入资料 ID，且不能存在任务、笔记、章节或阅读版本关联。应用永不删除外部原件。

每次生成阅读副本建立独立版本。原件更新后，旧标记仍在旧版，不能自动移动到新页。PPTX 可在“动画与视频”准备内嵌视频或动画播放版，再直接播放、拖动进度、全屏。动画是整份演示的线性视频回放，逐步点击交互仍通过“系统程序打开原格式”查看；旧 PPT 需先另存为 PPTX。文字标记可导出 Markdown；图形保存在数据库和完整备份中，第一版不写回原 PDF。

“图片文字识别（OCR）”支持本机中英文扫描页识别，每批 1–20 页；识别后上方课件搜索会合并 OCR 文字并支持跳页。也可选择单张 PNG/JPG（20 MiB 内）识别、复制和导出。原 PDF 不改写；公式、手写和模糊文字需人工核对。

OCR 文字和视频播放副本保存在工作区根目录的 `cache/<dataset>/`，可重新生成，不纳入完整备份。需要永久保留的识别文字请复制到笔记或导出。托管的原 PPTX/PDF 始终完整备份；外部引用的原件缺失时，恢复后无法重新生成其动画或内嵌视频。播放缓存按固定阅读版本校验，原件更新不能与旧页码混用。

完整备份包括数据库、全部托管正文、阅读 PDF、笔记历史、任务、章节、标记及进度。外部原格式文件只备份索引，即使有阅读 PDF，也不表示原 PPT 已备份。恢复先保留旧数据，再恢复到新目录、验证并切换，可回滚。旧 schema 1 备份可恢复并升级新的副本，原备份不改写。详见 [备份手册](docs/BACKUP_RESTORE.md)。

## 运行依赖和当前边界

- 已有独立环境：Python 3.14.3、Streamlit 1.65.0、pytest 9.1.1；未修改 Conda、ROS、SRTP 或系统配置。
- PDF.js 5.6.205、字体、CMap、WASM 及许可证已放入 `assets/pdfjs`，不从 CDN 加载。
- PDF 结构检查复用本机已有 bundled Python 中的 pypdf，默认在当前用户 `.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe`。迁移电脑时需准备带 pypdf 的 Python，并用进程变量 `PLW_PDF_PYTHON` 指定。当前为本机可运行源码版，不是独立安装包。
- PPT 转换使用 PowerPoint 与 PowerShell 7，仅打开独立任务目录内的复制件，不退出用户 PowerPoint。转换超时或失败时可手动导出 PDF。
- 当前采用单页阅读、左侧缩略图、区域高亮，支持本地课件文字查找（按匹配页列出，最多 200 个匹配页，支持停止查找）。扫描件先进行 OCR 再搜索。连续滚动、文字选择高亮、笔压/防误触、批注写回 PDF 留待优化。
- OCR 使用 Windows 自带识别引擎及已存在的中英文语言资源，PDF/图片渲染复用 bundled Python 的 pypdfium2/Pillow。没有下载模型或安装系统组件；迁移电脑需核对这些运行条件。
- 动画导出使用本机 PowerPoint，480p、最多 300 页、等待上限三分钟，可能受复杂字体/媒体影响。内嵌视频优先 MP4/WebM；链接媒体不联网加载，带活动对象的演示不自动导出。浏览器实际解码还取决于视频编码；PDF 内嵌多媒体未接入。超时保留独立作业副本，不退出用户 PowerPoint，不能保证 Office 已释放导出窗口。
- Markdown 图片不自动加载，避免笔记预览请求外部图片。第一版以文字、公式及资料关联为主。
- 同一课件多个标签页冲突时会显示保存失败；保留未保存内容后，在“阅读器维护”中点击“重新载入阅读器”。专注全屏可点击“退出专注”退出；文字批注仍在常规页面下方。
- 复杂 PPT 字体、SmartArt、原生公式和大文件长期压力仍需真实课程样本验证。生成后应抽查关键页面。

## 私人网站与多端使用

已提供独立的私人网站候选入口、账号设置脚本、覆盖 HTTP/WebSocket 的登录保护、HTTPS 代理模板与代码打包工具。**当前日常入口仍只允许本机访问，尚未部署外网网站**；网站账号在目标服务器上设置，现有本地版不会被强制加密码。当前候选版为 Windows 单进程，尚未移植 Linux。详见 [部署候选版手册](docs/DEPLOY_PRIVATE.md)。

选定服务器和域名后，还需目标机器独立安装、真实证书、备份、跨网络手机/iPad验收，再迁移已确认的学习资料。网站候选版保留 PPT 原件上传/下载，以上传导出的 PDF 作为阅读方案，不启动桌面 PowerPoint 或 Windows OCR；这些功能继续在本地版提供。网站在线编辑需要网络，下载到设备的 PDF 可离线阅读；尚未实现整站离线缓存和离线编辑合并。方案与验收顺序见 [私人网站计划](docs/PRIVATE_WEBSITE_PLAN.md)。

## 验收与历史入口

```powershell
Set-Location -LiteralPath 'E:\Projects\PLW'
& '.\.venv\Scripts\python.exe' -X utf8 -B -m pytest -q
```

测试只使用 `.sandbox` 合成数据。结果见 [PROJECT_STATUS](docs/PROJECT_STATUS.md)。不要把学习资料放入测试临时目录。

`--m0`、`--m1`、`--m2` 保留早期合成入口。日常使用默认 `app.py`；历史数据库不自动升级。旧文档保存在 `docs/history`。已有环境无需安装依赖；未来重建请使用专属虚拟环境及 `requirements.lock.txt`，不要复用其他项目环境。
